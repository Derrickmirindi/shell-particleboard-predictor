# Shell Particleboard Predictor

A research-oriented web application for predicting the mechanical and physical properties of shell-based particleboard materials using machine learning. The project applies a linear regression-based predictive model to estimate key board performance indicators from lignocellulosic shell composition data and related explanatory variables.

## Overview

The valorization of agricultural and agro-industrial shell residues has become an important area of interest in sustainable materials engineering. Shell-based biomasses such as macadamia shell, hazelnut shell, almond shell, walnut shell, coconut shell, palm kernel shell, and related lignocellulosic by-products present significant potential as alternative raw materials for the manufacture of composite boards.

This project introduces a predictive interface that estimates selected particleboard properties from shell composition parameters. By integrating machine learning into a user-friendly web application, the tool supports preliminary material evaluation, comparative analysis, and educational demonstration in the field of biomass-based panel development.

## Objective

The primary objective of this project is to provide an accessible predictive system capable of estimating important particleboard properties from shell-derived material characteristics. More specifically, the application is designed to:

- Predict modulus of rupture (MOR).
- Predict internal bond strength (IB).
- Predict thickness swelling (TS).
- Support comparison among multiple shell feedstocks.
- Illustrate the relevance of biomass chemistry in engineered board performance.

## Methodological Basis

The predictive approach implemented in this application is based on the XGBoost algorithm, a gradient-boosted decision tree method widely used for high-performance regression and classification tasks. In this context, the model is used to map input variables associated with shell composition to output variables representing board performance.

The application focuses on lignocellulosic descriptors, including:

- Cellulose content.
- Hemicellulose content.
- Lignin content.
- Ash content.

These variables are particularly relevant because they influence bonding behavior, dimensional stability, structural rigidity, and the overall performance of bio-based composite panels.

## Application Features

The web interface enables users to interactively explore predictive outputs for different shell materials. The current version includes:

- A structured shell-composition reference table.
- Prediction cards for key board properties.
- Formula-based and model-oriented presentation of outputs.
- A visually organized layout for educational and demonstration use.

The interface is intended not only as a practical tool, but also as a conceptual bridge between biomass characterization and data-driven materials prediction.

## Scientific Relevance

This project aligns with broader efforts in sustainable engineering, circular bioeconomy research, and the development of value-added products from underutilized agricultural residues. By translating shell composition data into interpretable performance predictions, the tool contributes to:

- Resource-efficient utilization of biomass waste.
- Reduced dependence on conventional wood raw materials.
- Rapid screening of candidate shell feedstocks.
- Improved understanding of structure-property relationships in bio-composites.

## Scope and Limitations

The predictions generated by this application should be interpreted as model-based estimates rather than as substitutes for laboratory testing. Material performance in real manufacturing conditions may also depend on additional variables such as particle size distribution, resin content, pressing temperature, board density, moisture condition, and processing methodology.

Accordingly, this tool is best understood as a decision-support and research-demonstration platform for preliminary evaluation.
